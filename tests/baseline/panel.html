            私有仓库凭据
            未设置
          

          
私有仓库需要只读 Token 才能检测更新。它只存在本机 config/github_token（已被 .gitignore 排除），任何接口都不会返回它。

          

            
            
            
          

          

          

            怎么生成只读 Token？
            
    
              
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    2. 
              
  2. Repository access 选 Only select repositories，只勾选本项目的仓库
    3. 
              
  3. Permissions → Repository permissions：Contents 设为 Read-only（Metadata 会自动变成 Read-only）
    4. 
              
  4. 生成后复制粘贴到上面保存；Token 只在保存时校验一次
    5. 
            

            
也可以用经典 Token（Tokens (classic)），只勾 repo 一项即可。
