## 问题修复
1. 分享卡原来偏大，分享视频卡默认宽度从 320px 收到 180px，卡里的字号、缩略图、留白都按卡宽换算，整张卡一起变小。
2. cloudflared 更新改成「先查再下」：打开面板时先问一次 GitHub，版本号后面标出新版本；点「更新 cloudflared」时若已经是最新，只提示一句，不再白下 50MB、也不停隧道。

## 功能新增
1. 控制面板「外观」精简：删除「面板配色」「查看器配色」两个分组；「字体」和「面板布局」只保留界面字体、聊天字体、圆角、侧栏宽度、字号缩放、阴影强度。
2. 「查看器布局与字号」删除气泡上下内边距、气泡左右内边距、气泡最大宽度三项，其余保留。
3. 原来的「分享卡宽度」改成「分享视频卡宽度」，并新增「分享评论卡宽度」；两项都是 140–360px，卡片里的字、缩略图和留白按各自宽度等比缩放。旧配置里的分享卡宽度会自动沿用到分享视频卡。
4. 分享视频 / 图文 / 动图 / 文章改成「封面 + 播放三角 + 左下角作者」，封面比例跟随作品本身，竖屏横屏都不裁歪；封面下方新增标题条，最多两行。
5. 分享评论改成「评论 + 分割线 + 缩略图 + 来自视频／来自图文 + 两行标题」，和抖音客户端一致；点卡片打开抖音官网对应作品。
6. 设置 → 外观顶部不再显示三块实时预览，改设置时直接看面板本身的变化。
