## 问题修复
1. 修复外来设备可无限次尝试面板密码的问题：连续输错同样会锁定登录入口并记录设备
2. 修复修改面板密码后已登录设备仍可继续访问的问题：改任意一道密码都会作废全部登录态
3. 修复镜像站下载的 cloudflared 程序无完整性校验的问题：下载后核对官方 SHA-256，不符自动换源重下
4. 修复聊天表情图片的文字说明转义不完整的问题
5. 修复本机设置密码后部分测试用例误报失败的问题：测试与真实配置完全隔离

## 功能新增
1. 面板密码新增防爆破机制：与访问密码同一套锁定规则（连错锁定、时间翻倍、单独暂停），本机输入不受影响
2. 设置页新增「面板密码 · 信任设备 / 需手动确认 / 登录保护」三个设备管理列表
3. 局域网访问的设备列表统一显示局域网与公网来源的设备，删除时如两道锁均有记录则提示一并删除
4. 改密码后页面自动弹出登录框：管理面板 5 秒内自动检测登录态失效，查看器操作时即时检测
5. 登录框新增锁定倒计时与设备暂停提示文案
