## 资源包少一张、更新弹窗被遮挡，并补上几处说明

这一版修了两个「看着像玄学」的小毛病，另外补了几句说明文字。

### 修好：下载资源包总有一张下不下来（213/214）

- 抖音给 `[加功德]` 那张表情的官方图片是 **PNG**，不是 WebP，而下载器只认 WebP，于是它每次都被算作失败，点多少次都补不上；加参数、换请求头也变不出 WebP；
- 现在按图片的真实格式存盘（WebP / PNG / JPG / GIF 都认），伪装的「错误页」照样会被挡下；
- 前端地址不用改（仍然是 `/emoji/名字.webp`），由后端按名字把几种扩展名都认下来；
- 顺带修正了清单里 `[加功德]` 的 sha256（原来那个和任何一份文件都对不上）；
- 本机已经下过 213 张的，重新点一次「下载资源包」就会补齐。

### 修好：检查更新时，各版本更新内容被遮挡

- 版本卡片以前会被压扁：列表是「竖排 + 可压缩」的排法，卡片默认能被挤小，于是文字被卡片自己裁掉，滚动条也不出现；
- 现在卡片保持原样，装不下就由列表滚动；弹窗也不会再高过屏幕（窗口矮、字号放大都不会），「依次执行…」说明与「自动重启」勾选固定显示。

### 文案

- 「下载资源包」弹窗里常驻一句说明：这是聊天查看器里文字表情（例如 `[憨笑]`）的图片，来自抖音官方；不下就一直按文字显示；
- 下载失败时写明是哪几张没下下来；
- README 顶部补一行辅助完成说明。

### 升级说明

面板页面是服务启动时读进内存的，更新后请重启一次服务（面板 → **日志** → **重启服务**），上面这些文案与布局改动才会生效。
