## 问题修复
1. 分享卡（视频 / 图文 / 动图 / 文章卡片）的封面改成采集时存到本机，链接过期后不再显示「封面已失效」；升级后的第一次采集会把老记录里的封面统一补一遍（只补这一次）。
2. 合并转发记录和「选择哪个是你自己」弹窗的打开、关闭改成淡入淡出，不再瞬间闪现。
3. 版本号不再按提交次数推算：发版号以 GitHub 上的版本标签为准，面板「检查更新」只比较版本号，读不到本地提交历史时也不会再猜数字。

## 功能新增
1. 聊天窗口顶部新增「数据洞察」：星期 × 小时热力图、消息排行、最常用的文字表情、第一次聊天与最长连续互聊等友谊数据、常聊关键词，全部在本机现算。
2. 语音条新增倍速按钮（1x / 1.25x / 1.5x / 2x），正在播放的那条点击后立刻生效，新播放的也会沿用当前倍速。
3. 导出新增「单文件 HTML」：一个会话（可按日期区间选一部分）导成一个独立的 .html 文件，图片内联在文件里，双击用浏览器就能看。
4. 去掉「开发者模式」开关：「私有仓库凭据」和「局域网访问」对所有用户直接显示可用，老用户已保存的凭据、局域网与公网配置原样保留。
