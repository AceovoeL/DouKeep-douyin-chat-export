## 删解析记录真的会删了；解析被占时也能一键改过来

### 「彻底移除」不再留下孤儿解析记录

cloudflared 自己只会**建**解析和**覆盖**解析，没有「删解析」这个功能 —— 而旧代码发的
`--delete` 根本不是它的开关。坑在于：cloudflared 遇到不认识的开关，打完一句
`Incorrect Usage` **照样退出 0**，于是程序以为记录删掉了、面板也不再提示，那条记录就
一直留在域名上，指着一条已经不存在的隧道（域名打开就是 Cloudflare 530 / 1033）。

这一版：

- **「彻底移除」改走 Cloudflare 接口删记录**：从本机授权凭据里取出接口令牌，按域名找到那条
  记录再删掉，不再依赖 cloudflared 的命令行。
- **认得出假成功**：接口走不通、退回命令行时，只要输出里出现 `Incorrect Usage` /
  `flag provided but not defined`，就判成「没删掉」，面板会照实提示去 Cloudflare 页面手动删。
- 只删**指向隧道**的记录（`CNAME → *.cfargotunnel.com`）：域名上的 MX、SPF、DKIM 之类
  记录，程序不会碰。

### 解析记录被占时：面板给一个「把解析改到这台电脑」

挂载时如果域名上已经有别的解析记录（比如上一台电脑留下的），程序**依然不覆盖**，但面板会：

- 在挂载结果页和设置页各给一个 **把解析改到这台电脑** 按钮；
- 点一下才带 `--overwrite-dns` 把记录改指向本机这条隧道，改成功后那条提示自动消失。

### 升级说明

- 更新后请重启一次服务（面板 → **日志** → **重启服务**）。
- 以前用旧版本「彻底移除」过、域名解析还挂着的机器：更新后再点一次「彻底移除」就能清掉。
