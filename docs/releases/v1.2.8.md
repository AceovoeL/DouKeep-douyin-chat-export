## 1.2.7 没发出来的原因：一条新测试只在 Windows 上写得通

v1.2.7 的代码本身没问题，但它带的一条新测试用了 Windows 风格的路径
（`C:\somewhere\<隧道ID>.json`）。CI 跑在 Linux 上，那里的 `os.path.basename()`
**不认反斜杠**，于是取不出文件名、断言失败 —— 整个 Python 测试 job 变红，
跟着 Release 也被跳过，所以 v1.2.7 没有发布出来。

这一版只改这一处：

- `configured_tunnel_uuid()` 不再用 `os.path.basename()`，改成按**两种分隔符**
  （`\` 和 `/`）切文件名，Windows 和 Linux 上读同一种 config.yml 结果一致；
- 对应那条测试也改成两种路径写法各验一次。

功能上 v1.2.8 和 v1.2.7 **完全一样**（都是这次「把解析改到这台电脑」的修复），
差别只在测试写法。v1.2.7 的说明见 `docs/releases/v1.2.7.md`。

### 升级说明

- 更新后重启一次服务（面板 → **日志** → **重启服务**）。
- 上一版没收到更新提示的，直接从 v1.2.6 升到 v1.2.8 即可，内容是一样的。
