## 问题修复
1. 「喂精灵」卡以前一律按新版外观画：2026 年 7 月那批老消息里没有背景图字段，卡片上半部分于是整块空白、连消息自带的那张精灵图也不显示，现在按抖音客户端的样子补上浅色渐变底纹和精灵图。
2. 老版「喂精灵」卡的标题和副标题以前写死成「邀请你一起喂精灵／精灵爱吃这个，你也来喂」，与消息里真实的「你还没有喂精灵~」「一起喂解锁彩蛋效果」不符，现在照抄消息原文。
3. 「邀请更改为姐妹火花」「你们已更改为姐妹火花」两张卡片以前只显示一行白字，现在按抖音客户端的样子画出来：头像、火花图标、标题、副标题和按钮都还原，副标题后面那支小箭头也不再歪。
4. 上述两张卡片不再居中显示，改成跟着发送者分左右；卡片下方不再冒出一个英文单词「bullet」（那是抖音给卡片记的互动状态，不是用户发的表情）。
5. 卡片上那颗火花以前写死成姐妹火花那一张，兄弟、伴侣、死党火花会被画错图，现在一律用抖音接口给的图片，是什么火花就画什么。
6. 修好一个只影响 Windows 的老问题：卡片图本地找不到时本该自动再下一次，但路径分隔符判断写错了，这个补救动作在 Windows 上从没生效过，只能一直显示碎图。
7. 修好「对方邀请你一起养小火人」这种长标题被截成「对方邀请你一起养小…」的问题，现在收一点字号让它排得下，更长的会换行。
8. 小火人 AI 每组消息的最后一条以前会被误标成「已编辑」，现在不再误标。
9. 视角切到对方之后，双方昵称以前会一起变成对方的昵称，现在各自显示正确的名字；在一个会话里切过视角后点开另一个会话，也回到自动认出来的那个视角，不再串会话。
10. 精灵自己发的表情以前被当成普通消息存下来、图一直没有下载，现在也纳入自动补图，采集时会把以前缺的那批一起补回来。
11. README 里「设置我」「小火人」以及消息类型清单的说法按上面的新行为更新。

## 功能新增
1. 新增「喂精灵」卡的老版外观：整张卡用项目自带的浅色渐变底纹，叠上抖音给的精灵图和消息里的标题、副标题，按钮仍是那颗只做展示的「去喂食」。
2. 采集喂精灵卡时把卡片上那张精灵图也存下来，并沿用抖音自己的文件名（`hotstick_card.png`），链接过期也能正常显示。
3. 新增「聊天火花」关系卡的解析模块与单元测试，同族的小火人、合养精灵卡不会被误判成这张卡；采集时会把卡片上那颗火花下载到本地。
4. 「邀请你一起养小火人」「我们开始养小火人啦」这类合养小火人卡（邀请、开始合养、纪念三种）也按客户端的样子画出来，按钮只做展示点不动，人称跟着「这条是不是我发的」变。
5. 小火人（精灵 AI）发的消息昵称固定显示「精灵AI」，后面挂一枚灰底小签写它的性格设定（如「腹黑傲娇」），不再跟着会话名走。
6. 搜索结果里搜到这些卡片时显示卡片上的那句话，不再直接吐出整段原始数据。
7. README 与 NOTICE 补上新增的界面素材来源和卡片图的存放位置。
