## 用自己的域名从外网打开面板和聊天记录（公网访问），并修好一批会卡住的地方

这一版主要加了一块新功能：**公网访问** —— 不用公网 IP、也不用在路由器上开端口，填一个托管在
Cloudflare 的域名，程序自己把本机服务接上去。同时把「设备管理」做得更细，修好了几处用起来会
卡住的地方，并把启动入口和面板文案梳理了一遍。

### 新功能：公网访问（用自己的域名）

- 在 **设置 → 局域网访问 → 公网访问** 点「挂载到公网」，填域名即可：程序会自己准备 cloudflared
  （首次约 50MB，带实时进度）→ 让你在浏览器里授权一次 → 建隧道 → 建解析 → 起隧道 → 从公网
  确认一次，每一步都显示在弹窗里。
- **挂载日志就在弹窗里滚动显示**（步骤提示、下载百分比、cloudflared 自己的输出）；失败时日志
  会留着，并把 cloudflared 的原话贴出来。「日志」页也新增了一份 **公网挂载**，可以事后翻。
- 没设访问密码也能挂：会先红字警告风险、要你二次确认。公网访客和局域网设备**共用同一把访问密码**。
- 关闭公网访问只停隧道进程，域名和云端记录都留着；「彻底移除」才会连隧道和解析记录一起删。
- cloudflared 一律**以无可见窗口的方式**运行；凭据存在项目目录 `config/cloudflared/`（不进仓库）。

### 设备管理：新增「需手动确认」

- 同一台设备**连续输错 5 次访问密码**会被暂停，不允许它继续猜（局域网和公网都管）；被暂停的
  设备打开解锁页时**看不到密码框**，只看到一句说明（告诉你去主机面板里解除）。
- 面板新增 **需手动确认** 板块（放在「信任设备」下面）：**一行一台设备**，右侧写明原因
  （例如「连续输错访问密码 5 次」），确认是自家设备后点「解除」，它才能重新输入密码。
- 解除之后**刷新页面立刻就能重新输密码**（以前刷新还会停在「已暂停」那一版，得手动去掉网址后缀）。
- 顺手把 **公网访问** 提到了 **信任设备** 上面，顺序更合直觉。

### 顺手修好

- **「信任设备」不再一台设备显示成两台**：同一个浏览器登录两次会留下两条记录，以前会并排显示成
  两台设备；现在按设备合并成一行，「不再信任」也把同一台的所有记录一起清掉。
- **聊天查看器的「我是谁」**：单聊里两边不再同名，群聊弹窗里也能选到自己。
- **双击启动**：第一次双击「启动服务（双击）.bat」（还没走过 `start.html`）会先帮你打开
  `start.html` 做首次环境检查，然后**自己结束、不启动服务**；检查通过后再双击一次就正常启动。
- **一批确认框的标题/按钮文字**：以前「恢复默认外观」顶着「确认全量采集」、解除设备暂停和关闭
  局域网/公网顶着「不再信任」—— 现在都说自己的话，并加了测试盯住这一类问题。

### 修好：授权那一步写不进凭据

- 有些电脑上的安全策略会**按程序路径**挡住 cloudflared 往用户目录写凭据（报 Access is denied）。
  现在凭据改放项目目录；万一还是写不进去，会自动改用一份临时副本运行，并把证书搬回项目目录。
- 授权链接铺成**可复制的文字**；服务以管理员身份运行时会提前提示常见的浏览器权限弹窗。

### 升级说明

- 更新后请重启一次服务（面板 → **日志** → **重启服务**）。
- 公网访问首次使用需要在浏览器里授权一次；凭据存在 `config/cloudflared/cert.pem`（不进仓库）。
