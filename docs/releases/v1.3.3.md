## 问题修复
1. 采集消息时，图片和表情的存档名以前是按消息号（图片）或链接哈希（表情）取的，看不出是什么；现在改成用链接里那截名字，抖音给的名字是什么就存成什么（例如 `hotstick_card.png`）。
2. 链接里带着抖音加的图片处理后缀时（形如 `xxx~tplv-x-get:large.image`）会把后缀砍掉再存，不会出现一长串带符号的文件名。
3. 两条链接恰好同名时不再覆盖：内容不一样就给第二张加一小截哈希区分，内容一样则直接复用已存的那张，不重复下载。
4. 链接里给不出正经文件名时（只有域名、或带异常字符）自动退回原来的命名方式，不会写出奇怪的文件名。

## 功能新增
1. 图片与表情的扩展名按实际下载到的格式判定，抖音那种不带后缀的 ID 名也能存成正确的 `.jpg` / `.png` / `.webp` / `.gif`。
2. 「本地有没有下过」的检查同时认新旧两种命名，升级后老图片照常显示、不会被当成没下过而重复下载。
3. 新增单元测试锁住新命名规则：名字取自链接、处理后缀要砍掉、同名不同图不许覆盖、同一张图不重复下载。
