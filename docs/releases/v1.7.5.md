## 问题修复
1. 检查更新不再依赖本地 git 记录，也不再数提交条数换算版本号：直接读 GitHub 上已发布的版本号比大小，从别处拷来的副本也能正确判断有没有新版本。
2. 更新提示里不再出现「落后 N 个提交」，改为按版本列出说明，不会再有版本号和更新内容对不上的情况。
3. 更新源还没有发布过任何版本时，面板会明确说清楚原因，而不是给一句笼统的失败提示。

## 功能新增
1. 「关于」页的更新弹窗改成按版本展示发布说明：每个版本标题、发布日期和「发布页」链接，展开可看这一版具体改了什么。
2. 发现新版本、更新完成的提示正文直接摘取各版本发布说明的前几条，一眼能看出这次带来了什么。
3. README 与控制面板的功能说明做了一次精简和顺序调整：先讲要装什么、怎么启动，再去掉重复啰嗦的段落，新用户更容易看懂。
