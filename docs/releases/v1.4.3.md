## 功能新增
1. 更新 cloudflared 的弹窗里直接给出镜像站和 GitHub 官方两条下载链接，以及文件要放到的绝对路径，下载慢时可以用自己的下载工具（比如 IDM）下好再放进去。
2. 更新弹窗「取消更新」左边新增「我已放入指定位置」：点一下就会停下项目内的下载，自动核对这个位置的文件版本与最新版是否一致，一致就直接安装。
3. 项目内自动下载改为先走镜像站、镜像都不通再回到 GitHub 官方地址，国内网络下更新会快很多。
4. 点「我已放入指定位置」之后，下载几乎立刻停下（以前网速慢时要等十几秒才停），按钮文案改成「已停止下载」。
