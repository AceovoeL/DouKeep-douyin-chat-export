## 公网挂载日志的时间不再「差 8 小时」

那份日志（`config/logs/cloudflared.log`）的行首时间一直是**世界时（UTC，结尾带 Z）**——这是
cloudflared 自己的规矩，面板追加的行也跟它保持一致，免得同一份文件里混着两种时间。可是拿它
和自己的钟一对，就会以为差了 8 小时、像是坏了。这一版只改「看起来」的地方：

- 面板 **日志 → 公网挂载** 现在**按本机时间显示**（文件里存的仍是世界时，格式一点没变）。
  「后端服务」「重启过程」那两份本来就是本机时间写的，没有动。
- 日志文件**新写入时会在开头加一行说明**：行首是世界时、面板日志页已按本机时间显示。
  只写一次，不会反复出现。
- 日志页的说明文字补上了时间口径，省得下次再有人对不上。

挂载弹窗里那块实时日志一直是本机时间，现在和日志页一致了。

### 升级说明

- 更新后请重启一次服务（面板 → **日志** → **重启服务**）。
- **已经存在**的日志文件不会补那行说明（只有新写入 / 新文件才会有），文件里的旧内容也不会被改动。
