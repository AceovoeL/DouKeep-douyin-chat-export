## 问题修复
1. 浏览器遇到解不了的 H.265 视频、自动重试转码时，不再报错打不开——以前这一步一定会失败，现在能正常转码播放，第二次播放直接命中缓存。
2. 搜索框里输入「&」这类符号时，高亮不再标错位置：以前一个「&」会亮出好几个黄条、把网页转义符号的内部也标上，输入「<」则一个都搜不到，现在都按真正看到的文字来标。
3. 定时采集的手写 cron 表达式里同时写了「每月几号」和「每周几」时，不再一直往后推迟——以前最多要空等七个月才执行，现在按标准规则「号数和星期几哪个对上都会跑」。
4. 补充历史语音转写时，偶尔拿不到本机设备标识不再整批放弃——现在会多试几次，这一轮的语音不会再全部白跑。
5. ChatLab 同步时，成员昵称的取值方式改成了明确指定「每条发送者最早那条消息上的昵称」，不再依赖数据库的偶然行为。
6. 聊天窗口在还没来得及挂上滚动监听就被关掉/切走时，不再留下一个反复空转的定时器。
