## 问题修复
1. 采集时单张表情或图片的连接被抖音图片服务器掐断（日志里的 WinError 10054）时不再直接放弃：会自动重试几次，通常第二次就能下下来。
2. 重试后仍然没下到的附件，只在日志里留一行「因网络中断没下到，下次采集会自动补齐」，不再弹「采集报错」并把整轮采集暂停两分钟；下次采集收尾会把它补回来，也可以点「下载历史图片」手动补。
3. 采集收尾「补齐缺图的消息」这行统计不再被当成错误弹窗——以前库里只要有一张永久补不上的图，每轮采集结束都会弹一次框并暂停采集。
4. 补上浏览器标签页缺失的网页图标：以前页面里只有引用、没有图标文件，地址栏显示的是空白。
