## 更多错误会弹窗，而且同一件事只弹一次

### 新增会弹窗的日志

以前这些行只会安静地写在日志里，面板不吭声，用户根本看不到：

- **`[!] 页面有二维码 → 登录态实际无效…`**、**`[!] 页面有验证码/滑块 → 触发了风控…`**、
  **`[!] 页面有登录按钮 → 大概率未登录`**、**`[!] IM SDK 完全未加载 → …`**：
  这四条是「这次为什么没抓到」的答案，现在**一行一个弹窗**（页面同时有二维码、IM SDK 又没加载时，
  会连着弹两个框，点「忽略并继续」依次过）；
- **`[!] 诊断失败: …`**：页面诊断自己都没跑起来，同样一行一个弹窗；
- **`[!] sec_uid 定向补取失败: …`**、**`[!] 无法找到会话「X」，跳过`**、**`[!] batch #N JS 端报错: …`**：
  这些是单个会话 / 单批消息的小毛病，**合并成一个弹窗**（一次运行只问一遍），
  免得几十个会话时一行一个框点到手软。

### 同一件事不再弹两次

日志里报过错的任务，随后带着非零退出码结束时，原来会**再弹一个「采集失败 (exit code N)」**，
同一件事要按两次「忽略并继续」。现在：

- 任务结束时**先把日志尾巴补扫一遍** —— 进程死得太快时，最后写下的那几行原来会被漏读，这是重复弹框的根因之一；
- 这一轮已经为日志里的错误行弹过框，就**不再弹退出码**，只把「采集失败 (exit code N)」补进那条错误的
  「错误内容」里（面板状态、右下角常驻提示、微信通知都照旧，信息不丢）；
- 只有**日志里没报错、进程却直接挂掉**，才会弹退出码框。

「刷新会话列表」原本是同一个毛病，一并修好了。
