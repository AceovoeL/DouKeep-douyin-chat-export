## 问题修复
1. 采集收尾不再反复去试早就过期的图片 / 实况图链接：补不下来的记进库里并冷却几天，只有手动点「下载历史图片」才全部重试，省掉每次结束前的白等。

## 功能新增
1. 会话列表和聊天标题新增抖音同款「火花」：显示图标与连续天数，图标在采集时按官方文件名存到本机，链接过期也不会变碎图；数据洞察弹窗顶部一并显示。
2. 控制面板「概览」页新增数据总览：今日与近 7 天消息、有消息天数、发言人数、消息构成、数据范围、本地保存情况与磁盘占用；统计放到后台算并缓存，页面不会被拖慢。
3. 聊天窗口工具栏与数据洞察弹窗显示「数据统计截止至」：取本次采集第一次拉取该会话消息的时刻，没有记录就不显示，不拿最后一条消息的时间顶替。
4. 新增表情包同步接口：按发送者列出已下载到本机的表情包目录（按图片内容去重、带使用次数与首末时间）和图片本身，只读、走 API token 鉴权。
5. 手机端浏览优化：锁定页面缩放、未选会话时自动展开会话列表、查找面板占满聊天区并加大按钮与输入框字号。
