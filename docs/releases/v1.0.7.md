## 聊天查看器：消息一律贴住自己那一侧，表情快捷回复里的表情也变成图片

### 我发的消息不再被下方那行标签挤离右边

聊天窗口里每条消息是「头像 + 一列内容（昵称、正文、时间与标签）」。这一列以前是普通块级排版：
列宽会被**同一列里更宽的那一行**撑开，而气泡、图片、卡片自己是「按内容收窄」的，
于是它们只能贴在**这一列的左边**，看起来就像没对齐：

- 短句（比时间行还窄的，例如「我去」「对的」「很呆」）离右边十几像素；
- 带「表情快捷回复 / 已编辑 / 仅看一次」标签的消息（时间行更宽，明细里还带表情和昵称）
  **实测能偏出一百多像素**，气泡挂在消息中间而不是贴着右边。

现在这一列改成纵向 flex，每个子块各自贴住自己那一侧：**自己发的贴右、对方发的贴左**。
同一个原因造成的其它块也一起修好了：表情包 / 图片 / 视频封面 / 分享卡 / 商品卡 /
合并转发卡 / 引用回复块。

### 「表情快捷回复」明细里的表情记号换成图片表情

消息下方那行明细原来是当纯文本画的，所以显示成 `表情快捷回复 [爱心] | 某人`。
现在跟正文走同一套渲染：本地有图的记号（`assets/emoji/爱心.webp`，网页端是 `/emoji/爱心.webp`）
直接变成图片表情，图片高度仍然跟随所在文字大小（这一行是 10px 字，图也约 13px 高）；
资源包还没下载时照旧退回原来的文字记号，昵称里的尖括号之类也会被转义。

### 顺带做的事

- **群聊里也能点「设置我」了**：以前只有正好两个人的会话才出现这个按钮，群聊里根本点不到，
  于是群里所有消息都挤在左边；选择框加了「超出屏幕可滚动」，人多也不会顶出画面。
- README 的「浏览」一条补上左右对齐与群聊设置「我」的说明。
- 前端补一个用例：`[爱心] | 昵称` 这种明细里表情会变图片、昵称里的标签会被转义。

### 说明

- 改动在 `frontend/src/components/MessageList.vue`（外加 README 与一个前端用例）；
  前端是构建产物，升级后**要重新构建一次前端**（`cd frontend && npm run build`）并刷新页面才看得到。
