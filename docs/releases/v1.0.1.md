## 存储布局调整：`data/` 与 `config/` 分家

`data/` 现在**只放聊天记录**，其他东西全部搬进新的 `config/` 目录，备份时一眼就能分清
「哪些删了会心疼」。

| 目录 | 放什么 |
|------|--------|
| `data/` | 聊天记录：`chat.db` 数据库、下载的图片/表情/语音/视频、导出与数据库备份 |
| `config/` | 设置与运行状态：面板设置 `panel_config.json`、私有仓库凭据 `github_token`、登录态 `browser_profile/`、日志 `config/logs/` |

### 升级说明

- **老版本升级不用手动搬**：服务启动时会自动把 `data/` 里的设置、凭据、登录态和日志搬到
  `config/` 对应位置（幂等，目标已存在不覆盖，单个文件搬不动只记一行日志、不影响启动）。
- 面板 **日志** 页显示的路径随之变成 `config/logs/server.log` / `config/logs/restart.log`，
  「打开日志文件夹」打开的是 `config/logs/`。
- 备份建议：备份 `data/` 与 `config/` 两个目录。
- 没有改动数据库、媒体文件和导出文件的位置（都留在 `data/`）。

### 其他

- 收掉了 11 处直接写死 `data` 路径的代码，路径统一由 `common/paths.py` 提供，避免以后再改漏。
- README 精简了重复说明，新增「数据放在哪」一节，按第一次使用的顺序重新梳理了安装与启动步骤。
