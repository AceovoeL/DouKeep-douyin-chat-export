## 启动时自动备好浏览器内核，不用再手动装 Playwright

这一版修的是「导入 Cookie 失败」的根子：不少人装完之后缺 Playwright 的浏览器本体，一导入
Cookie 就报一串英文（`Executable doesn't exist at ...chrome-headless-shell.exe`），
看上去像是「cookie editor 导出的 JSON 认不出来」，其实 JSON 早就通过了，是最后一步开不了浏览器。

### 修好：缺浏览器内核时自动下载

- 以前 `pip install` 只装 Playwright 这个 Python 包，**浏览器本体要另外下**，而一键启动的脚本
  从来没下过它。现在「启动服务（双击）.bat」→ `start.ps1`（macOS / Linux 的 `start.sh` 也一样）
  每次启动都会核对一遍版本：**缺了就自动下载**（下载约 300 MB、占盘约 700 MB，先走国内镜像，失败再回官方 CDN）。
- 一并解决「以前装过、Playwright 升级之后旧内核作废」的情况：那时任何要开浏览器的功能都会报
  `Executable doesn't exist`，现在启动时就会把对应的新内核下好。
- 下载失败不拦启动：服务照样起得来、已有记录照样能看，双击时的窗口和启动日志里会写清楚
  各自要用的功能会失败，以及手动补装的命令。

### 环境检测跟着改

- 面板 **关于 → 环境检测** 和首次运行的检测页里，「Playwright 浏览器内核」从**可选**改成**必需**；
  由于启动脚本每次都会把它装好，这一项**默认算已满足**（不会再让第一次用的人被它挡在门外），
  说明里写明「启动时自动装」以及真装不上时怎么手动补。
- 磁盘要求从 1 GB 提到 **2 GB**（浏览器内核占盘约 700 MB），检测页的提示同步改了。

### 说明文字

- README 里「Playwright 要手动装」的旧说法去掉了（现在只有 ffmpeg 是可选依赖），
  一键启动的步骤说明里补上「下载浏览器内核」这一步。
- 新增「导入 Cookie 失败？」一节：把几种提示分别是什么意思、该改哪儿，一条条列清楚。

### 升级说明

面板页面是服务启动时读进内存的，更新后请重启一次服务（面板 → **日志** → **重启服务**），
上面这些文案改动才会生效。
