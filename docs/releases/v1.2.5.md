## 修好「把解析改到这台电脑」按钮：开关位置写错了

上一版接出来的那个按钮，一点就报：

```
This command expects the format "cloudflared tunnel route dns <tunnel name/id> <hostname>"
```

原因是把 `--overwrite-dns` 追加在了隧道名和域名**后面**。cloudflared 只认位置参数**前面**的
开关，后面多出来的东西被它当成格式错误，命令直接失败（面板于是提示「改解析没成功」）。

现在改成：

```
cloudflared tunnel route dns --overwrite-dns <隧道名> <域名>
```

并加了一条测试，把「带头开关」和「不带头开关」两种情形的**完整命令行**都断言下来 ——
以后再写错顺序，测试会立刻变红。

### 升级说明

- 「把解析改到这台电脑」这个按钮要在**那台电脑**上也更新到这一版才好使。
- 更新后重启一次服务（面板 → **日志** → **重启服务**）。
